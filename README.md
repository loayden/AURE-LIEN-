# AURELIA Storefront

Minimal Next.js + Tailwind demo storefront.

Quick start

1. Install dependencies:

```bash
npm install
```

2. Run development server:

```bash
npm run dev
```

Notes
- Images use Unsplash remote URLs; Next.js remote image domain is configured in `next.config.js`.
- If you prefer local assets, add images under `public/products/` and update `lib/data.ts`.
